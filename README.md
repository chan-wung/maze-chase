# Cheese Chase (치즈 체이스)

생쥐가 미로에서 치즈를 모두 먹고 고양이 네 마리를 피하는 브라우저 게임입니다. 순수 JavaScript와 `<canvas>`로 만들었고 게임 엔진은 쓰지 않았습니다.
미로 모양·캐릭터·그래픽은 모두 직접 만들었습니다.

## 실행

```bash
npm install
npm run dev      # 개발 서버 (http://localhost:5173)
npm run build    # dist/ 에 배포용 빌드
npm test         # 게임 규칙 테스트
```

Node.js 20.19 이상(또는 22.12 이상)이 필요합니다. 휴대폰에서는 같은 와이파이로 개발 서버 주소에 접속하면 됩니다.

## 조작

| 환경 | 방법 |
|---|---|
| 키보드 | 방향키 또는 WASD. 갈림길 전에 미리 눌러 두면 그 칸에서 꺾습니다 |
| 터치 | 화면 어디서나 스와이프, 또는 화면 아래의 방향 패드 |
| 일시정지 | P · Space · Esc 키, 또는 왼쪽 위 ⏸ 버튼. 멈춘 화면에서 다시 누르거나 화면을 터치하면 계속합니다. 다른 탭으로 가면 자동으로 멈춥니다 |
| 시작·다시 하기 | 시작 화면과 게임 오버 화면에서 아무 키나 누르거나 화면을 터치 |

터치 조작은 터치 기기에서 자동으로 켜지고, 주소 끝에 `?touch=1`을 붙이면 PC에서도 켤 수 있습니다. 오른쪽 위 버튼으로 한국어와 영어를 바꿀 수 있습니다.

## 규칙

- 치즈 조각은 10점, 큰 치즈는 40점입니다. 큰 치즈를 먹으면 고양이가 잠시 겁먹어서 잡을 수 있고, 연속으로 잡으면 150 → 300 → 600 → 1200점입니다.
- 모든 치즈를 먹으면 다음 단계로 넘어가고, 단계가 오를수록 빨라지며 겁먹는 시간은 짧아집니다.
- 목숨은 3개이고 8000점에 하나 더 받습니다. 최고 점수는 브라우저에 저장됩니다.
- 고양이는 쫓아오는 방식이 서로 다릅니다.

| 고양이 | 쫓는 방식 |
|---|---|
| 주황 줄무늬 (chaser) | 생쥐가 서 있는 칸을 그대로 쫓습니다 |
| 검정 턱시도 (ambusher) | 생쥐가 가는 방향 3칸 앞을 노려 길목을 막습니다 |
| 회색 (flanker) | 줄무늬 고양이와 생쥐 3칸 앞을 잇는 선을 두 배로 늘린 곳으로 가서 반대편에서 끼어듭니다 |
| 삼색 (shy) | 멀면 쫓고, 6칸 안으로 가까워지면 제 구석으로 도망갑니다 |

흩어지기(6초·6초·4초·4초)와 쫓기(18초·18초·22초)가 번갈아 오고 마지막은 끝까지 쫓기입니다. 잡힌 고양이는 반투명한 모습으로 집에 돌아가 다시 나옵니다.

## 구조

```
src/
  game/    규칙 (화면·키보드를 모르므로 node 에서 바로 테스트)
    maze.js    미로 문자열을 읽고 벽·문·터널 판정
    actor.js   칸 위 이동 (칸 중심에서만 방향을 정함)
    player.js  플레이어
    ghost.js   고양이 4종의 목표 칸과 길 고르기
    game.js    점수·목숨·단계·모드 시계
  render/  canvas 그리기
  ui/      터치 조작
  app/     i18n (ko/en)
tests/     maze · player · ghost · game · i18n
```

미로는 `src/game/maze.js`의 문자열 배열(`LEVEL_ROWS`)을 고치면 바뀝니다.
`#` 벽, `.` 치즈, `o` 큰 치즈, `-` 고양이 집 문, `P` 생쥐 시작, `G` 고양이 집 안, 공백은 치즈 없는 길입니다. 고양이의 구석 좌표(`ghost.js`의 `GHOST_DEFS`)는 21×21 미로 기준입니다.
